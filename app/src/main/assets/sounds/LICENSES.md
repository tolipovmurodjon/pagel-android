# Ambient sounds for the habit timer

All six recordings are CC0 1.0 (public domain dedication), found on Wikimedia Commons and checked against the
licence shown on each file page. CC0 needs no credit; the authors are named here anyway.

Each file was cut to the steadiest stretch of its source, closed into a seamless loop (the last seconds crossfade into
the first), levelled to about -23 LUFS, and stored as mono Opus in Ogg (56 kbps). Nothing else was changed.
